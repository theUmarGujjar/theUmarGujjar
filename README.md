### 🤖 ML Gaps & Loopholes — My Research Interest

> *Most people build ML models. I study where they break.*

- **Adversarial Examples** — crafting inputs that fool models with imperceptible changes
- **Data Poisoning** — how corrupted training data silently degrades model integrity
- **Model Inversion Attacks** — extracting private training data from a trained model
- **Evasion Attacks** — bypassing ML-based intrusion detection and malware classifiers
- **Robustness vs Accuracy tradeoffs** — understanding the fundamental tension in secure ML
